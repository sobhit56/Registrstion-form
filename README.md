# Registrstion-form
A **modern, responsive registration form** built with HTML, CSS, and JavaScript.  
It includes **real-time validation**, a **password strength meter**, **file upload with drag & drop**, and a **live progress tracker** to enhance user experience.

---

## ✨ Features

- ✅ Real-time form validation  
- 🔐 Password strength indicator  
- 🧮 Character counter (max 500 characters)  
- 📂 File upload with drag & drop support  
- 📊 Live form progress tracker  
- 🎉 Success modal on submission  
- 📱 Fully responsive (mobile & tablet friendly)

---

## 📁 Project Structure

📦 Registration-Form

📄 index.html # Main HTML structure

📄 style.css # Styling & responsive design

📄 script.js # Validation & interactivity


## 🚀 Quick Start

1. Download or clone the repository  
2. Place all files in the **same directory**  
3. Open `index.html` in any modern browser

## ✔️ Validation Rules

- **Email**: Must be a valid email format  
- **Password**: Strength indicator (weak → strong)  
- **Age**: Numeric and valid range  
- **File Upload**: Allowed file types & size limit  
- **Required Fields**: Must be filled before submission
